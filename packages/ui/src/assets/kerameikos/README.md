# Kerameikos product identities

The three SVGs are the original light-surface `mark-small.svg` exports for use below 192 pixels. The live wordmark follows the upstream typeface, spacing and color. Palamedes+ uses the Palamedes mark, and VorOrt uses Agoros. The bundled typeface is covered by [the SIL Open Font License](OFL.txt). [Upstream artwork and design guide](https://github.com/sebastian-software/kerameikos/tree/dcdf84b3e2f21e47401b081a56c9a68b6ec0fd3d)
