# Consulting service illustrations

Generated on October 12, 2026 with the built-in Image Gen tool. The illustrations
use a technical editorial direction: near-white warm-neutral backgrounds,
graphite, off-white, satin aluminum, and smoked glass with small burgundy accents.

| Source                   | Service area                    | Original        |
| ------------------------ | ------------------------------- | --------------- |
| component-grid.png       | Architecture and modernization  | 1448 × 1086 PNG |
| terminology-catalog.png  | Internationalization            | 1448 × 1086 PNG |
| hands-on-engineering.png | Engineering and team enablement | 1448 × 1086 PNG |

These are editorial metaphors for the service content, not project screenshots
or technical diagrams. The component grid establishes the material and lighting
reference for the terminology catalog and engineering illustration.

The PNG files are unchanged generated originals. The component imports them with
`?bunny` and renders `BunnyImage`; builds and deployment use the shared immutable
asset manifest and responsive Optimizer variants. The near-white backgrounds
support the neutral Consulting canvas; burgundy remains a restrained accent.

[prompts.json](prompts.json) contains the complete generation prompts and reference
relationships for all three selected illustrations.
