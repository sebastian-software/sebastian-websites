# Consulting image assets

The closing ridge-path landscape.

| Asset                                                                     | Native dimensions |
| ------------------------------------------------------------------------- | ----------------- |
| [Consulting — path to an overlook](photography/consulting-ridge-path.png) | 1536 × 1024       |

The ridge-path scene was reconstructed from the selected concept using built-in ImageGen.

The founder portraits are private photographs and stay outside this public repository. The site
renders retouched edits of the 2024 shoot from the shared asset zone as
`shooting-2024-edit/color_09092024-3-retouched.png` (Sebastian Werner) and
`shooting-2024-edit/color_09092024-4-retouched.png` (Sebastian Fastner), following ADR-0014. The
consultant profiles crop the edits of photos 15, 31, and 32 from the same folder; `app/lib/photos.ts`
holds the crops.

The profile project history uses the client logos in `company/` as SVG, and the printed company
block uses `logo-consulting-print.svg`, a copy of the brand's transparent Consulting logo.
