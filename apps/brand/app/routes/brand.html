Usage

Import color tokens directly via URL. All assets are served with CORS headers for cross-origin use.

Color Tokens

/* All palettes */
@import url("");

Token Usage

/* By name */
color: var(--software-lagoon);

/* By role — same color */
color: var(--software-vivid);

Each palette provides two ways to reference colors:
By name — the unique color name, e.g. var(--software-lagoon)
By role — a semantic alias consistent across all palettes, e.g. var(--software-vivid)
night
0.15 — Near-black, deepest tone
dark
0.25 — Dark backgrounds, heavy text
base
0.40 — Primary brand color
vivid
0.50 — Strongest chroma, accents
bright
0.70 — Lighter accent, highlights
paper
0.95 — Near-white, backgrounds
