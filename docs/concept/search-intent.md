# Search questions and content homes

This is the provisional content map for issues #128, #132, #133, and #134, prepared on
16 November 2026. It uses the published offer, project evidence, and the Consulting
communication guide. Search Console queries, search volumes, and a prospect-question
sample were not available. The phrases below are candidate reader questions, not measured
keywords or claims of demand.

The first audience is CTOs, engineering leads, and maintainers evaluating help with an
existing web product. Consulting's goal is a relevant introductory conversation. Software
introduces products; Open Source helps developers find projects; the tech blog explains
engineering experience. These roles do not change to fit a keyword.

domain and has a self canonical and a language counterpart.

Architecture review answers **which direction and why**. Modernization answers **how to
implement an agreed change**. Internationalization answers **how language support becomes
part of an established product**. A useful overview at `/services` connects these decisions
and keeps its existing anchors; it does not need to repeat each complete brief.

The first three offers are prioritized because they are already offered and have public
proof, not because their query volume is known. Each page explains fit, inputs, working
steps, deliverables, constraints, responsible experience, and the same primary action:
book an introductory conversation. There is no new fixed-price, availability, duration,
or outcome promise.

## How to revise the priorities

Use the [search baseline procedure](../operations/search-visibility.md) to replace
assumptions with observations. Keep German/English, branded/nonbranded, and site roles
separate.

- If relevant impressions land on the wrong page, improve its links and clarify the
  intended content home before adding another near-duplicate page.
- If prospect questions cluster around one of the offers, develop that page's proof and
  practical answers first. A clear inquiry is more relevant than broad, unrelated traffic.
- If an indexed page gets relevant impressions but few clicks, compare its title and
  description with the actual question and alternatives shown in the result.
- If organic visitors reach a page but do not take the intended next step, check the
  offer, fit, evidence, and working action before attributing the problem to rankings.
- If there is not enough history, keep the conclusion provisional. Do not infer that an
  offer has no demand from an unindexed or newly published page.

The account owner supplies query and indexing evidence for #127. The team supplies actual
prospect questions. Record private exports and source reconciliation outside this public
repository. Summarize only evidence that may be public. No search-volume, ranking, or lead
projection is introduced here.
