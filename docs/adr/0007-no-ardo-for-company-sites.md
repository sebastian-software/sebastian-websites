# Company sites use Ardo

[ADR-0019](0019-software-site-on-ardo.md) now covers every implemented website.
The former choice of React Router for company sites, followed by an Ardo exception
for Software alone, is replaced by ordinary Ardo projects with a shared branded
shell. Custom marketing layouts remain website-owned; adopting Ardo does not
replace them with its default documentation layout.
