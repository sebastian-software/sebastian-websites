# English is the project language

Every document, identifier, comment, and commit message in this repository is written in
English, including concept and strategy documents. The owners work in German, and the earlier
website repository mixed English ADRs with German strategy documents; one language removes the
question of where each kind of text belongs and keeps the project readable for tools, agents,
and outside contributors.

## Consequences

- German brand and domain terms get one canonical English name in [GLOSSARY.md](../../GLOSSARY.md).
- Site content is a separate matter: every site is published in German and English
  ([ADR-0006](0006-language-by-tld-english-source.md)).
- German wording quoted from existing sources stays in German when the exact phrase matters,
  for example the value statement "Erfahrung. Klarheit. Begeisterung."
